# 使用指南

## 安装与运行

```bash
uv sync                       # 安装依赖（需 uv，Python 3.11）
uv run python main.py         # 启动应用
```

应用为中文界面，四页导航：**表情包** / **收藏集** / **下载** / **设置**（下载页、设置页在下方）。

## 页面功能

### 表情包页

- **按 ID 查询**：输入表情包 ID（如 `53`）查询单个表情包，展示包名、ID、表情数量、GIF 标记与表情缩略图网格；包内确实有动图时才出现「下载动图 (GIF)」选项，勾选后下载到本地，或「加入下载」进队列。已下载过的包会显示「已下载过」。
- **全部表情包**（需登录）：点击「拉取全部表情包」获取 B 站全部表情包列表，以分页卡片网格展示（每页 20 个、每张卡用第一张表情做封面、显示包名与 ID，卡片随窗口宽度自适应填满），支持关键词过滤（包名或 ID）；点击卡片进入该包详情并下载。
  - 列表结果**缓存到本地 24 小时**，避免每次拉取都请求 B 站；需要最新数据可点「强制刷新」。
- **点表情看大图**：详情里点任意表情缩略图，弹出遮罩查看器（见下「图片查看器」）。

### 收藏集页

- 输入关键词（如 `2233`）搜索 B 站装扮 / 收藏集，结果以**四列竖版海报卡片**展示（海报 + 名称 + 「收藏集 / 装扮」类别徽标，装扮用灰色、收藏集用橙色标记）。
- **点卡片进入详情**：预览收藏集内容（图片网格按视口动态撑满；视频以折叠列表展示，点标题展开），选择下载模式（**静态图片 / 动态视频 / 图片+视频**）后「下载到本地」，或「加入下载」进队列。已下载过的收藏集会显示「已下载过」。
- **多选加入下载队列**：勾选「多选」后卡片出现勾选框，可勾选多个 → 「加入下载」→ 到「下载」页统一批量下载。
- **「仅看收藏集」默认勾选**（装扮无法下载，默认只看收藏集），取消勾选可实时看回全部结果（无需重新搜索）；点击无收藏集的装扮会提示「无收藏集详情」。
- **点卡面看大图**：详情里点任意卡面图，弹出遮罩查看器（见下「图片查看器」）。

### 图片查看器

在**表情包详情**或**收藏集详情**里点击任意图片，即可全屏查看原图：

| 操作 | 效果 |
|---|---|
| 悬浮左右箭头 / `←` `→` 方向键 / 鼠标滚轮 | 切换上一张 / 下一张 |
| 点击图片下方的页码点 | 直接跳到该张 |
| `Esc` / 点击图片外的暗色区域 / 右上角 ✕ | 关闭 |

图片下方显示名称与 `当前 / 总数`；超过 15 张时隐藏页码点，只保留数字。

> GIF 表情在查看器里**只显示第一帧**（静态图），下载得到的仍是完整动图。

### 下载页（下载队列）

- **会话级队列**（仅本次运行，重启清空），**混合表情包 + 收藏集**：在表情包 / 收藏集页多选「加入下载」后在此统一管理。
- 队列以**响应式卡片**展示（宽窗口两列、窄窗口自动退回单列；封面自适应），支持**全选 / 删除选中 / 清空 / 下载选中**。
- 每张卡片显示**内容数量**（如「24 张图片」「12 张图片 · 3 个视频」），数量在卡片滚动到可见时后台读取，读取中显示「内容读取中…」；进过详情页的项直接复用已有数据。
- 「下载选中」按类型拆分批量下载（表情包 → 收藏集），共用一条进度条。
- **全部文件下载成功的项会自动移出队列**（本地已存在、被跳过的文件同样算成功），有文件失败的项留在队列里可重下；移除时会弹一条提示告知移除了几项。

### 设置页

版式为分组卡片（账号 / 下载 / 外观），每行一项设置，右侧是对应控件；带 ⌄ 的行点一下展开填写。

- **账号**
  - **B 站 Cookie**：展开后填写，格式 `SESSDATA=...; bili_jct=...`，点「保存」。未填写时该行默认展开。Cookie 仅保存在本机配置，不会上传。
  - **访问权限**：点「验证」确认当前 Cookie 能拉取全部表情包。
  - **配置文件**：显示 `config.json` 的实际路径。
- **下载**
  - **下载目录**：副标题显示当前目录；「选择文件夹」挑目录、「打开下载文件夹」直接在资源管理器打开；展开后可手动粘贴路径。
  - **代理**：协议（HTTP / HTTPS）+ IP / 域名 + 端口，主机名留空表示不使用代理。
  - **下载线程数**：1–16。
  - **保存下载设置**：下载目录、代理、线程数改完要点这里才生效。
- **外观**：**应用主题**切换（跟随系统 / 浅色 / 深色）。

## Cookie 获取

部分功能（全部表情包、收藏集下载）需要登录。Cookie 获取方式：

1. 浏览器登录 bilibili.com；
2. 打开开发者工具（F12）→ Network，任意请求的请求头里复制 `Cookie` 字段；
3. 通常只需 `SESSDATA=...; bili_jct=...` 即可。

在「设置」页展开「B 站 Cookie」粘贴后保存，再到「访问权限」行点「验证」确认。

## 下载说明

- 表情包下载到 `下载目录/<表情包名> [包ID]/`（防同名覆盖），GIF 动图优先取 `gif_url`。
- 收藏集下载到 `下载目录/<收藏集名>/`，图片为 `.png`、视频为 `.mp4`。
- 下载过程显示进度条；完成后弹出统计（成功 / 失败 / 跳过），可点「打开所在文件夹」。
- 下载不支持中途安全取消：运行中关窗会提示，退出可能残留 `.part` 临时文件。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 全部表情包提示「需要登录」 | 未填 Cookie 或已过期，到设置页填写 / 更新 |
| 全部表情包列表为空 / 0 个 | Cookie 无效或接口未返回数据；确认 Cookie 有效后「强制刷新」 |
| 收藏集搜索「没有结果」 | 属正常空态（关键词无匹配），换个关键词 |
| 下载部分文件失败 | 文件级失败会自动重试；仍失败会在统计中提示，可重新下载 |
| 界面英文 / 主题不符 | 在设置页切换主题 |

## 数据与配置位置

- 配置文件：`%APPDATA%/biliEmojiDD/config.json`（Cookie、下载目录、主题等）
- 全部表情包缓存：`%APPDATA%/biliEmojiDD/all_packages.json`（24 小时有效）
