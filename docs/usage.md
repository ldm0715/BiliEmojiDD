# 使用指南

## 安装与运行

### 用安装包（推荐）

到 [Releases](https://github.com/ldm0715/BiliEmojiDD/releases) 下载：

- `BiliEmojiDD-Setup-<版本>.exe` —— 安装包，装到当前用户目录（`%LOCALAPPDATA%\Programs\BiliEmojiDD`），
  不需要管理员权限，会创建开始菜单快捷方式。卸载时会问一句是否连配置和缓存一起删（默认保留）。
- `BiliEmojiDD-<版本>-win64.zip` —— 便携版，解压后直接运行 `BiliEmojiDD.exe`。
- `SHA256SUMS.txt` —— 上面两个文件的校验和，介意的话可以核对一下。

### 从源码运行

```bash
uv sync                       # 安装依赖（需 uv，Python 3.11）
uv run python main.py         # 启动应用
```

应用为中文界面，五页导航：**主页** / **表情包** / **收藏集** / **下载** / **设置**（下载页、设置页在下方）。

## 页面功能

### 表情包页

- **按 ID 查询**：输入表情包 ID（如 `53`）查询单个表情包，展示包名、ID、表情数量、GIF 标记与表情缩略图网格；包内确实有动图时才出现「下载动图 (GIF)」选项，勾选后下载到本地，或「加入下载」进队列。已下载过的包会显示「已下载过」。
- **全部表情包**（需登录）：点击「拉取全部表情包」获取 B 站全部表情包列表，以分页卡片网格展示（每页 20 个、每张卡用第一张表情做封面、显示包名与 ID，卡片随窗口宽度自适应填满），支持关键词过滤（包名或 ID）；点击卡片进入该包详情并下载。
  - 列表结果**缓存到本地 24 小时**，避免每次拉取都请求 B 站；需要最新数据可点「强制刷新」。
- **点表情看大图**：详情里点任意表情缩略图，弹出遮罩查看器（见下「图片查看器」）。

### 收藏集页

- 输入关键词（如 `2233`）搜索 B 站装扮 / 收藏集，结果以**四列竖版海报卡片**展示（海报 + 名称 + 「收藏集 / 装扮」类别徽标，装扮用灰色、收藏集用橙色标记）。
- **点卡片进入详情**：内容预览分「静态图片 / 动态视频」两个标签——图片网格按视口动态撑满、点图可全屏查看；切到「动态视频」即开始播放，**左侧播放器 + 右侧视频网格**，点右侧封面切换视频（收藏集没有动态卡时该标签不可点）。选择下载模式（**静态图片 / 动态视频 / 图片+视频**）后「下载到本地」，或「加入下载」进队列。已下载过的收藏集会显示「已下载过」。
- **播放控制**：播放/暂停、进度条、音量，以及**上一个 / 下一个视频**（到头会自动置灰）与**全屏**按钮。全屏后可用方向键切换、Esc / 点空白处 / 右上角 ✕ 退出。
- **视频加载**：视频先在后台下到临时目录再播（走应用内代理设置），首次点开会短暂显示「正在缓冲」；已经整包下载过的收藏集直接播下载目录里的文件，秒开。临时文件在关闭应用时自动清理。
- **多选加入下载队列**：勾选「多选」后卡片出现勾选框，可勾选多个 → 「加入下载」→ 到「下载」页统一批量下载。
- **「仅看收藏集」默认勾选**（装扮无法下载，默认只看收藏集），取消勾选可实时看回全部结果（无需重新搜索）；点击无收藏集的装扮会提示「无收藏集详情」。
- **点卡面看大图**：详情里点任意卡面图，弹出遮罩查看器（见下「图片查看器」）。

### 图片查看器

在**表情包详情**或**收藏集详情**里点击任意图片，即可全屏查看原图：

| 操作 | 效果 |
|---|---|
| 悬浮左右箭头 / `←` `→` 方向键 / 鼠标滚轮 | 切换上一张 / 下一张 |
| 点击图片下方的页码点 | 直接跳到该张 |
| `Esc` / 点击图片外的暗色区域 / 右上角 ✕ | 关闭 |

图片下方显示名称与 `当前 / 总数`；超过 15 张时隐藏页码点，只保留数字。

> GIF 表情在查看器里**只显示第一帧**（静态图），下载得到的仍是完整动图。

### 下载页（下载队列）

- **会话级队列**（仅本次运行，重启清空），**混合表情包 + 收藏集**：在表情包 / 收藏集页多选「加入下载」后在此统一管理。
- 队列以**响应式卡片**展示（宽窗口两列、窄窗口自动退回单列；封面自适应），支持**全选 / 删除选中 / 清空 / 下载选中**。
- 每张卡片显示**内容数量**（如「24 张图片」「12 张图片 · 3 个视频」），数量在卡片滚动到可见时后台读取，读取中显示「内容读取中…」；进过详情页的项直接复用已有数据。
- 「下载选中」按类型拆分批量下载（表情包 → 收藏集），共用一条进度条。
- **全部文件下载成功的项会自动移出队列**（本地已存在、被跳过的文件同样算成功），有文件失败的项留在队列里可重下；移除时会弹一条提示告知移除了几项。

### 设置页

版式为分组卡片（关于 / 账号 / 下载 / 缓存 / 外观），每行一项设置，右侧是对应控件；带 ⌄ 的行点一下展开填写。

- **关于**
  - **代码仓库**：显示 `ldm0715/BiliEmojiDD`，点「打开仓库」跳转 GitHub。
  - **检查更新**：点一下查最新发布版本。已是最新会提示一句；有新版本则弹窗显示更新说明，
    点「下载并安装」会下载安装包、**关闭应用并启动安装程序**（安装包会先做 SHA-256 校验，
    对不上直接丢弃且不运行）。也可以点「发布页」自己去 GitHub 下。
  - **自动检查更新**：开着的话每次启动应用后在后台悄悄查一次。**没有新版本或查不通时完全不打扰**，
    只有发现新版才在右上角出一条带「查看更新」的提示。不想让它联网就关掉。
  - **下载加速**：直连 GitHub 慢或者拉不动时用镜像。**这和下面的「代理」是两回事**：
    代理改的是所有请求走哪条线路，加速源只改下载安装包时用的地址，两者可以同时用。
    - 下拉里选一个源，或选「自动」让它直连失败后按顺序依次尝试。
    - 点「测速」实测每个源的延迟，结果用三色标签标出：**绿=良好**（1 秒内）、
      **橙=一般**（通了但慢）、**红=错误**（连不上 / 超时）。测完把快的拖到前面，
      「自动」模式就会优先用它。
    - 展开卡片可以**拖动手柄调整顺序**；自定义源还能点铅笔改地址、点垃圾桶删除
      （内置的三个只能排序）。
    - 最下面一行可以**自己添加加速源**，填 `https://你的域名/` 这种前缀式反代地址即可，
      不写 `https://` 也会自动补上。
    - 不论走哪个源，安装包下载完都会用**从 GitHub 直连取到**的 SHA-256 校验一遍，
      对不上直接丢弃且不会运行。
  - **开源许可**：本项目为 GPL-3.0，点「查看协议」看完整条款。
- **账号**
  - **B 站 Cookie**：展开后填写，格式 `SESSDATA=...; bili_jct=...`，点「保存」。未填写时该行默认展开。Cookie 仅保存在本机配置，不会上传。
  - **访问权限**：点「验证」确认当前 Cookie 能拉取全部表情包。
  - **配置文件**：显示 `config.json` 的实际路径。
- **下载**
  - **下载目录**：副标题显示当前目录；「选择文件夹」挑目录、「打开下载文件夹」直接在资源管理器打开；展开后可手动粘贴路径。
  - **代理**：一个开关 + 一个地址框。开关关着时地址框不可编辑，应用**彻底直连**（连 Windows 系统代理都不读）；打开后填完整地址即可，如 `http://127.0.0.1:7890`，也支持 `socks5://` 与 `http://用户名:密码@主机:端口`。「测试」按当前填的值（不必先保存）向 `https://api.bilibili.com/x/garb/v2/mall/home/search`（收藏集搜索接口，不需要 Cookie）发一次真实请求——ping 通不代表那个端口上有可用代理。失败提示里会写明**被测的那个地址**与接口。
  - **下载线程数**：1–16。
  - **保存下载设置**：下载目录与线程数改完要点这里才生效。**代理不用**——开关一拨、地址框按回车或点到别处就立刻生效，代理卡的副标题会显示当前真正在用的地址。
- **外观**
  - **应用主题**：跟随系统 / 浅色 / 深色。
  - **字体渲染**：默认 (DirectWrite) / FreeType。文字发糊或笔画有彩边时换 FreeType 试试，**重启应用后生效**。

## Cookie 获取

部分功能（全部表情包、收藏集下载）需要登录。Cookie 获取方式：

1. 浏览器登录 bilibili.com；
2. 打开开发者工具（F12）→ Network，任意请求的请求头里复制 `Cookie` 字段；
3. 通常只需 `SESSDATA=...; bili_jct=...` 即可。

在「设置」页展开「B 站 Cookie」粘贴后保存，再到「访问权限」行点「验证」确认。

## 下载说明

- 表情包下载到 `下载目录/<表情包名> [包ID]/`（防同名覆盖），GIF 动图优先取 `gif_url`。
- 收藏集下载到 `下载目录/<收藏集名>/`，图片为 `.png`、视频为 `.mp4`。
- 下载过程显示进度条；完成后弹出统计（成功 / 失败 / 跳过），可点「打开所在文件夹」。
- 下载不支持中途安全取消：运行中关窗会提示，退出可能残留 `.part` 临时文件。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 全部表情包提示「需要登录」 | 未填 Cookie 或已过期，到设置页填写 / 更新 |
| 全部表情包列表为空 / 0 个 | Cookie 无效或接口未返回数据；确认 Cookie 有效后「强制刷新」 |
| 收藏集搜索「没有结果」 | 属正常空态（关键词无匹配），换个关键词 |
| 下载部分文件失败 | 文件级失败会自动重试；仍失败会在统计中提示，可重新下载 |
| 界面英文 / 主题不符 | 在设置页切换主题 |
| 检查更新报网络错误 | GitHub 直连不通。到「设置 → 关于 → 下载加速」选一个镜像，或先配好代理 |
| 提示「安装包校验失败」 | 下到的文件与官方校验和不符（镜像返回了错误内容 / 传输损坏）。文件已被丢弃且不会运行，换直连或换个镜像重试 |
| 装了新版还提示有更新 | 少见。多半是发布方的 tag 与应用内版本号没对齐，可去发布页手动确认 |

## 数据与配置位置

- 配置文件：`%APPDATA%/biliEmojiDD/config.json`（Cookie、下载目录、主题等）
- 全部表情包缓存：`%APPDATA%/biliEmojiDD/all_packages.json`（24 小时有效）
- 更新安装包：`%TEMP%/biliEmojiDD-update/`（用完可以随手删）
- 用安装包装的程序在 `%LOCALAPPDATA%\Programs\BiliEmojiDD`；**卸载默认不动上面这些数据**，
  重装后 Cookie 和设置还在。
