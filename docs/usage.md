# 使用指南

## 安装与运行

```bash
uv sync                       # 安装依赖（需 uv，Python 3.11）
uv run python main.py         # 启动应用
```

应用为中文界面，三页导航：**表情包** / **收藏集** / **设置**。

## 页面功能

### 表情包页

- **按 ID 查询**：输入表情包 ID（如 `53`）查询单个表情包，展示包名、ID、表情数量、GIF 标记与表情缩略图网格；可勾选「下载动图 (GIF)」后下载到本地。
- **全部表情包**（需登录）：点击「拉取全部表情包」获取 B 站全部表情包列表，以分页卡片网格展示（每页 20 个、每张卡用第一张表情做封面、显示包名与 ID），支持关键词过滤（包名或 ID）；点击卡片进入该包详情并下载。
  - 列表结果**缓存到本地 24 小时**，避免每次拉取都请求 B 站；需要最新数据可点「强制刷新」。

### 收藏集页

- 输入关键词（如 `2233`）搜索 B 站装扮 / 收藏集，结果卡片展示封面、名称、价格与「收藏集 / 装扮」标记。
- 点击卡片进入详情：预览收藏集内容图片、显示视频数量，选择下载模式（**静态图片 / 动态视频 / 图片+视频**）后下载到本地。
- 没有可下载收藏集的装扮会提示「无收藏集详情」。

### 设置页

- **账号（Cookie）**：填写 B 站 Cookie，格式 `SESSDATA=...; bili_jct=...`。保存后点击「验证表情包访问权限」确认可用。Cookie 仅保存在本机配置，不会上传。
- **下载目录**：选择表情包 / 收藏集的保存位置。
- **外观**：主题切换（跟随系统 / 浅色 / 深色）。

## Cookie 获取

部分功能（全部表情包、收藏集下载）需要登录。Cookie 获取方式：

1. 浏览器登录 bilibili.com；
2. 打开开发者工具（F12）→ Network，任意请求的请求头里复制 `Cookie` 字段；
3. 通常只需 `SESSDATA=...; bili_jct=...` 即可。

在「设置」页粘贴后保存，再点「验证表情包访问权限」确认。

## 下载说明

- 表情包下载到 `下载目录/<表情包名>/`，GIF 动图优先取 `gif_url`。
- 收藏集下载到 `下载目录/<收藏集名>/`，图片为 `.png`、视频为 `.mp4`。
- 下载过程显示进度条；完成后弹出统计（成功 / 失败 / 跳过），可点「打开所在文件夹」。
- 下载不支持中途安全取消：运行中关窗会提示，退出可能残留 `.part` 临时文件。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 全部表情包提示「需要登录」 | 未填 Cookie 或已过期，到设置页填写 / 更新 |
| 全部表情包列表为空 / 0 个 | Cookie 无效或接口未返回数据；确认 Cookie 有效后「强制刷新」 |
| 收藏集搜索「没有结果」 | 属正常空态（关键词无匹配），换个关键词 |
| 下载部分文件失败 | 文件级失败会自动重试；仍失败会在统计中提示，可重新下载 |
| 界面英文 / 主题不符 | 在设置页切换主题 |

## 数据与配置位置

- 配置文件：`%APPDATA%/biliEmojiDD/config.json`（Cookie、下载目录、主题等）
- 全部表情包缓存：`%APPDATA%/biliEmojiDD/all_packages.json`（24 小时有效）
